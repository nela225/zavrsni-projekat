
# Kafić Projekat - SI

### Opis
Jednostavna full-stack aplikacija za upravljanje proizvodima u kafiću.

### Tehnologije
* **Frontend:** JavaScript i CSS
* **Backend:** PHP
* **Baza:** MySQL
* **Auth:** Firebase

### Funkcije
* Prijava korisnika
* Pregled svih artikala
* Dodavanje novih artikala
* Brisanje artikala
